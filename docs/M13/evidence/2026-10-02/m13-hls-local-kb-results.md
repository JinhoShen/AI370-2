These options do not belong under any header in the configuration file. --platform <arg> Specify path to a platform specification (.xpfm) to target the current component or project to. --freqhz <arg> Specify a clock frequency in Hz. Important: If your HLS configuration file specifies platform= instead of part= you must use also use freqhz= instead of clock=. This is because the platform specifies a clock in freqhz form, and you can only override it using the same form. --part <arg> Specify a target device for the HLS component.
